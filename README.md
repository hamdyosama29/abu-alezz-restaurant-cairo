# مطعم أبو العز السوري — مدينة نصر (Abu Al-Ezz Al-Soury Restaurant)
### الموقع الإلكتروني ونظام إدارة المحتوى المدار عبر Pages CMS وGitHub وVercel

هذا المستودع يمثل الموقع الرسمي ونظام إدارة المحتوى المقترح لمطعم أبو العز السوري (مدينة نصر، القاهرة) والمبني وفق بنية:
**Headless Git-based CMS + Vercel Global Edge Hosting**.

---

## بنية المشروع (Project Structure)
```
├── .pages.yml                   # مخطط إدارة المحتوى الرسمي لمنصة Pages CMS
├── index.html                   # واجهة الموقع المتجاوبة (Apple-grade Responsive Design)
├── data/
│   ├── business.json            # بيانات وهوية المطعم وأرقام التواصل والعناوين
│   ├── menu.json                # قائمة الطعام والأسعار والتصنيفات والأطباق
│   └── offers.json              # العروض الأسبوعية والكومبو
└── public/
    └── images/                  # الصور المحملة عبر لوحة التحكم
```
